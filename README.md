# rvi
Rental Vulnerability Index Maps


# 📂 Project Structure

## 📂 data: Data Processing

* **`state_summaries.ipynb`**: used to generate the `combined.csv` `state_year_cards.json` file. This script processes raw output data to calculate state-level aggregates for each vulnerability indicator, ensuring that the "State Average" comparison in the info panel is pre-calculated for optimal performance.

* **`transform.R`**: Transforms the RVI calculation results (PCA output) by joining them with ABS spatial boundaries for 2011, 2016, and 2021. It standardizes coordinates to WGS84 and exports the final datasets as `tiles.geojson` and `data.json` for dashboard visualization.

* **`transform.R`**: Transforms the RVI calculation results (PCA output) by joining them with ABS spatial boundaries for 2011, 2016, and 2021. It standardizes coordinates to WGS84 and exports the final datasets as `tiles.geojson` and `data.json` for dashboard visualization.
* **`tippercanoe_cmd.txt`**: Contains the command to convert `tiles.geojson` into optimized vector tiles. It configures zoom levels (0–11), applies polygon simplification for better performance, and disables feature limits to ensure all RVI data is preserved.

## 📂 docs: Website 

* **`index.html`**: The application's entry point. It defines the layout for the map and the overlay UI panels, and manages the loading sequence of the project's core libraries, including **MapLibre GL**, **Deck.gl**, **Chroma.js**, and **Chart.js**.

* **`index.js`**: The central "brain" of the application. This file handles URL routing to load state-specific views and contains the `THEMES` configuration, which defines the colors, labels, and data-access logic for all the vulnerability indicators. It is responsible for initializing the high-performance map visualization.

* **`branding.js`**: Handles the introductory section of the side panel. It dynamically renders the project title, partner logos, and the "About" and "Data Sources" collapsible sections based on the current state configuration.
* **`controls.js`**: Manages the user interaction tools in the side panel. It provides the interface for switching between census years, searching for specific regions (SA2), and selecting different vulnerability indicators (themes), triggering real-time updates across both the map and the info panel.
* **`info_panel.js`**: Manages the detailed data view. This script dynamically builds a comparison table that juxtaposes state-level aggregate data against local-area statistics. It integrates **Chart.js** to render the detailed visualizations, such as distribution doughnuts and time-series trends.
* **`legend.js`**: Manages the visual legend for the map. It dynamically generates a color key based on the active theme and indicator type (categorical or continuous), utilizing **Chroma.js** to ensure visual consistency between the map colors and the UI.
* **`map.js`**: Manages the geospatial rendering engine. It implements high-performance vector tiles (MVT) to render thousands of local areas efficiently and handles the interactive logic for selecting regions, filtering by year/state, and displaying dynamic tooltips.
* **`selection.js`**: Manages the state of selected geographic regions. It implements a selection queue to handle multi-area comparisons (enforcing a maximum limit), and synchronizes these selections with the map's visual highlights and the detailed info panel.
